Question: what is machine learning 
Answer: Machine learning is programming computers to optimize a performance criterion using example data or past experience. It involves defining a model with parameters, and the execution of a computer program aims to find the optimal parameters for the model using training data or past experience. The model can be used for predictive purposes to make predictions in the future, descriptive purposes to gain knowledge from data, or both.
